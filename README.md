# 🌐 English-Hindi Machine Translation

An NLP-based Machine Translation system that translates English sentences into Hindi using Deep Learning and Sequence-to-Sequence learning techniques. The project demonstrates text preprocessing, tokenization, word embedding, encoder-decoder architecture, and LSTM-based neural networks for language translation.

---

## 📌 Overview

Machine Translation is one of the most important Natural Language Processing (NLP) applications. This project focuses on translating English sentences into Hindi using supervised learning techniques and neural sequence models.

The implementation includes complete data preprocessing, vocabulary generation, tokenization, model training, and translation prediction.

## ⚙️ Workflow

1. Load English-Hindi parallel dataset
2. Clean and preprocess text
3. Tokenize English and Hindi sentences
4. Create vocabulary dictionaries
5. Convert sentences into integer sequences
6. Pad sequences to equal length
7. Train Encoder-Decoder LSTM model
8. Generate Hindi translations
9. Evaluate translation results
